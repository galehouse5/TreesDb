New URL scheme (redirect map from legacy shapes lands in Phase 4, but the
URL-equivalence table in `web/parity/normalize.ts` is written now — doc 07
§6):

| New | Legacy |
|---|---|
| `/` → redirect `/map` | `/` → `/Map` (behavior preserved) |
| `/map`, `/api/map/markers`, `/api/map/{trees,sites,states}/{id}/info` | `/Map`, `/Map/AllMarkers`, `/Map/{id}/*MarkerInfo` |
| `/locations`, `/species` | `/Browse/Locations`, `/Browse/Species` |
| `/trees/{id}`, `/sites/{id}`, `/states/{id}` | `/Browse/{Trees,Sites,States}/{id}/Details` |
| `/species/{slug}` (+ `?site=`/`?state=` scoping) | `/Browse/Species/{bn} ({cn})/Details` (+ scoped forms) |
| `/search?term=` | `/Search?term=` |
| `/api/species/suggest?by=common|scientific` | `/Trees/FindKnownSpecies…` |
| `/export/...` (mirror legacy paths, lowercased) | `/Export/...` |
| `/photos/{id}/{size}` | `/Photos/{id}/{size}` |
| `/activity` | `/Browse/Activity` |

Species slug (D-011): `slugify(botanicalName) + '--' + slugify(commonName)`
(lowercase, spaces→`-`, strip non `[a-z0-9-]`). ETL parity adds a
uniqueness check over all (bn, cn) pairs; collision → fail loudly, decide
then.

## Task notes (read doc 01 sections before each)

- **P1-01**: layout (header nav: Map / Browse / Search / Import / Account,
  footer), units switcher posting to a route handler that sets the
  `unitsPreference` cookie (same name/values, 10-year expiry — doc 01 §7)
  and redirects back. Server components read it via `cookies()`.
- **P1-02**: `web/lib/units.ts` (float32 conversions, exact constants),
  `format.ts` (all format rules incl. half-away-from-zero rounding — doc
  07 §6), `coords.ts` (parse with 5-dp banker's rounding, DDM/DMS/DD
  formatting, planar minute distance), `species-hash.ts`. Golden tests
  from doc 07 §7.3 including the 200 scraped production values.
- **P1-03/04**: TanStack Table, server-side sort/filter/page via
  searchParams; page size 40; filter semantics = legacy `LIKE
  '%'+filter+'%'` per column (read `SpeciesBrowser`/`SiteBrowser` usage in
  `TMD.Infrastructure` repositories for the exact predicates and default
  sorts). Columns/values exactly as the legacy grid partials render them.
- **P1-05..08**: server components; every displayed value through
  `format.ts`. Grids embedded in detail pages: page size 10, sortable per
  the legacy column switches (read the controller actions cited in doc 01
  §1). Rucker indices from `computed_*` columns, formatted per RuckerIndex
  rules.
- **P1-09**: exact rank algorithm (doc 01 §4), 5/25 result caps + message
  rows; JSON shape for the header search widget mirrors legacy fields
  (Category/Subject/Description/Url) so extractor parity is trivial.
- **P1-10**: MapLibre + OSM raster tiles; client clusters nothing — apply
  the legacy zoom-band visibility (states 0–6, sites 7–13, trees 14+, with
  the "no contained coordinates" 0–30/7–30 exceptions); `/api/map/markers`
  returns the legacy JSON contract (doc 01 §9); info popups fetch the info
  endpoint. Marker icons: default pin vs photo thumbnail per legacy
  mapping config.
- **P1-11**: port `TreeCsvExporter` verbatim (doc 01 §8): 25 columns,
  quoted-all, CRLF, header unit suffixes, filename incl. units,
  `Content-Disposition`. One shared row-builder for all 8 endpoints; the
  query replicates `GetTrees` filter semantics.
- **P1-12**: `/photos/{id}/{size}`: fetch original from R2, resize with
  sharp per the size table (doc 01 §11 — fit vs center-crop vs border),
  cache variant to R2, long `Cache-Control`, fallback icon for missing
  blobs. Dimensions must match legacy math exactly (parity §5.5).
- **P1-13**: recent trips = last 40 site visits (legacy
  `BrowseController.RecentTrips`); activity page content from
  `MeasurerActivity` query.
